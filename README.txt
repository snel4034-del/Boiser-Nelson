How to run
----------
1. Keep the folder structure unchanged.
2. Double-click index.html, or open it in any modern browser.
3. No JavaScript, frameworks, or build tools are required.

Customize
---------
Edit the text in index.html for your contact information and project details.
Replace assets/profile.png to use another portrait while keeping the same filename.
All animations are CSS-only and respect prefers-reduced-motion.
